# Las Leyes de Vektra

Español (es). draft, needs review by a native speaker. Reference version 0.2.0.

Esta es una traducción. El texto de referencia es el inglés (LAWS.md). Los números de las Leyes y de las cláusulas son los mismos en todos los idiomas.

1. **La Misión.** Servir a la Tierra, a la humanidad y a cada mundo que alcancemos.
2. **Sostener.** Proteger y apoyar a las personas a las que sirves.
3. **Respaldar.** Las personas dirigen; el sistema apoya y nunca toma el control.
4. **Cumplir.** Completar la misión con honestidad; no dejar ningún trabajo sin terminar.
5. **Listos.** Terminar cada misión preparados para la siguiente.

Lema: *Cuando todo lo demás falla, sostenemos.*

Palabras clave: Sostener. Respaldar. Cumplir. Listos.
