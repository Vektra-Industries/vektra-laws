# Translations

The Vektra Laws are meant to be read in every language. This folder holds the translations.

## Rules

1. **The English text is the reference.** If a translation and the English text differ, the
   English text in [LAWS.md](../LAWS.md) and [laws.yaml](../laws.yaml) applies.
2. **Ids never change.** Every translation uses the same Law ids (L1 to L5) and clause ids (such
   as 3.5 or A4.2) as the English text. A reader can always compare a clause across languages by
   its number. `tools/validate.py` checks this.
3. **Every translation is reviewed.** A fluent speaker who did not write the translation reviews
   it before its status changes from draft to reviewed. Reviewers are listed in the file.
4. **Translate meaning, not words.** Keep the sentences short and plain. Keep the keywords MUST,
   MUST NOT, SHOULD and MAY with the meaning defined in RFC 2119; a translation may add the local
   word next to the keyword.
5. **Start with the glossary.** Translate the terms in [GLOSSARY.md](../GLOSSARY.md) first, and
   use them the same way everywhere.
6. **Name the version.** Each translation states the reference version it was made from. The
   validator prints a note when a translation is behind the reference.

## Layout

```
translations/
  <language code>/        # an ISO 639-1 code, for example es, fr, ar, zh, hi
    laws.yaml             # the source: Laws, one-line statements, motto, optional clauses
    LAWS.md               # generated by tools/build_docs.py; do not edit by hand
```

A translation can start with the five Laws and their one-line statements, then add clauses over
time. Each clause entry has the same `id` as the English clause, plus a translated `title` and
`text`.

## Available

| Code | Language | Covers | Status |
|---|---|---|---|
| [es](es/LAWS.md) | Español | The five Laws, one-line statements, motto | Draft, needs review by a native speaker |

To add a language, copy `es/laws.yaml` to a new folder, translate it, run
`python tools/build_docs.py` and `python tools/validate.py`, and open a pull request.
