# Reference adopters

Reference adopters apply the Vektra Laws in real systems and publish their results, so that other
adopters can see how the Laws work in practice. Any adopter, from any maker, can ask to be listed
here by opening a pull request with a published [ADOPT.md](../ADOPT.md) declaration.

| System | Maker | Kind | Profile | Conformance level | Status |
|---|---|---|---|---|---|
| Vektra Agent | Vektra | AI agent system | agents | None yet | Planned for v1.0 |
| Phryktor | Vektra | Sentinel agent | agents | None yet | Planned for v1.0 |
| vektra-reflex | Vektra | Guard and lesson tool for agents | agents (2.4, 4.6, 5.7, A2.1, A5.3) | None yet | Planned for v1.0 |

No system is listed with a conformance level until its declaration and evidence are published.
The v1.0 release needs each planned reference adopter to reach at least the Tested level (see
[ROADMAP.md](../ROADMAP.md)).
