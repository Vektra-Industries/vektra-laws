# Reference adopters

*This document is informative.*

Reference adopters apply the Vektra Laws in real systems and publish their declarations and
results. Any adopter, from any maker, can request a listing by opening a pull request that links to
a published declaration based on [ADOPT.md](../ADOPT.md). A listing is not an endorsement or a
certification by the owner or the steward.

| System | Maker | Kind | Profile | Conformance level | Status |
|---|---|---|---|---|---|
| Vektra Agent | Vektra | AI agent system | agents | None yet | Planned for v1.0 |
| Phryktor | Vektra | Sentinel agent | agents | None yet | Planned for v1.0 |
| vektra-reflex | Vektra | Guard and lesson tool for agents | agents (1.5, 3.12, 5.10, A1.1, A5.4) | None yet | Planned for v1.0 |

A conformance level is shown only after the declaration and its evidence are published. The
planned adopters listed above are products of the owner. Version 1.0 requires each planned
reference adopter to declare at least the Tested level (see [ROADMAP.md](../ROADMAP.md)).
