# Open questions

Only the questions that need a decision. Each one says what the current draft does.

## Needs a reviewer (by the version named)

1. **Spanish translation (v0.2).** A native speaker should review it, especially the Law names
   "Respaldar" (Hold), "Cumplir" (Finish) and "Listos" (Ready).
2. **Robots in shared space (v0.3).** Any motion in a space shared with people is level 3, so each
   such action needs a person's approval. That is not practical for a robot that works among
   people. Options: an approved per-mission scope that lists specific motions, or a stricter
   level 2 for low-force motion inside tested limits.
3. **Record signing (v1.0).** 5.4 says the record SHOULD be signed or keyed. Raise it to MUST by
   v1.0?
