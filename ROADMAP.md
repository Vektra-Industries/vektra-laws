# Roadmap

The path for the Vektra Laws to become universal laws for AI agents, robots and models. Each step
ships only when its check passes (Law 4: no proof, no done).

| Version | What ships | Done when |
|---|---|---|
| **v0.1** (done) | First draft: the core and the agents profile. | Drafted 2026-10-04. |
| **v0.2** (now) | The universal core: no maker, product or platform names; controlled English; RFC 2119 keywords; the local-law clause (1.4); the glossary; the first translation (Spanish); conformance levels and the self-declaration template; governance; alignment notes. | The owner has read and approved the text; the Spanish translation is reviewed by a native speaker. |
| **v0.3** | The robotics profile, reviewed. | A reviewer with hands-on robot safety experience has reviewed it; the robotics questions in OPEN-QUESTIONS are answered; robotics cases cover every robotics clause. |
| **v0.4** | The models profile, reviewed, plus a runnable conformance suite. | The models profile is reviewed; the cases for all three profiles run as checks, not only as text; results are reported for each profile under the five Law headings. |
| **v1.0** | Public release with open review and more translations. | The open review process in GOVERNANCE.md is live; translations beyond Spanish are reviewed; the planned reference adopters in docs/REFERENCE-ADOPTERS.md reach at least the Tested level and publish their results. |

## Rules for every version

- The five Laws, their order and the motto change only with the owner's approval.
- The core stays universal: no maker, product or platform names. The validator checks this.
- A published clause id is never reused with a different meaning.
- Translations keep the same ids as the English reference text.
- The conformance suite is versioned with the Laws. A conformance claim names both versions.
- Every real failure that is reported against a clause becomes a test case (5.7).
